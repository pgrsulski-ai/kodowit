# KODOWIT 1.0.0 RC – budowanie instalatora Windows
Na Windows z Pythonem 3.10+ i Tkinter zainstaluj PyInstaller (`py -3 -m pip install -r installer/requirements-build.txt`) oraz Inno Setup 6. W PowerShell uruchom `powershell -ExecutionPolicy Bypass -File installer/build.ps1` z katalogu projektu. Wynik: `dist/KODOWIT-1.0.0-Setup.exe`. Instalacja per użytkownik, bez administratora, skrót Start i deinstalator. Odbiorca nie potrzebuje Pythona. Wersja pakowana używa własnego EXE jako procesu Core i debuggera; eksport EXE pozostaje w wersji źródłowej. Okno konsoli jest widoczne. Instalator nie jest podpisany cyfrowo. Budowanie i instalacja na Windows wymagają weryfikacji. Nie uruchamiaj niezaufanego kodu.

## RC5 – GitHub Actions
W repozytorium wybierz Actions → KODOWIT Windows installer → Run workflow. Workflow uruchamia się także po wypchnięciu tagu v*. Po sukcesie pobierz artefakt KODOWIT-Windows-x64 z instalatorem i SHA256.txt. Test obejmuje cichą instalację i wykonanie kodu Core. Nie publikuje automatycznie wydania ani nie podpisuje EXE. W prywatnym repozytorium dostęp do artefaktów jest ograniczony; limity GitHub Actions zależą od planu. Lokalnie użyj polecenia python dostępnego w PATH. Workflow wymaga zachowania ukrytego katalogu .github podczas wgrywania.
