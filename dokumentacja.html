API i JSON (2.6)

z_json(tekst) odczytuje JSON, do_json(wartość) zapisuje JSON jako tekst. pobierz_json wykonuje asynchroniczne GET przez HTTPS, bez cookies. Serwer musi zezwalać na CORS (w podglądzie także dla origin null). Limit 1 MB, 10 sekund i 30 zapytań na uruchomienie. Nie umieszczaj kluczy API w kodzie.

zmienna dane = z_json("{\"miasto\":\"Kraków\"}")
wypisz(dane["miasto"])
pobierz_json("https://jsonplaceholder.typicode.com/todos/1", dane) {
 wypisz(dane["title"])
} inaczej (blad) {
 wypisz(blad)
}

Zakres obejmuje oba końce. Funkcje średnia, minimum i maksimum wymagają niepustej listy liczb.

KODOWIT 2.8 – scena 3D

Nowe bryły: piramida i torus. Każda przyjmuje x, y, z, szerokość, wysokość, głębokość i kolor. Opcja osie: prawda pokazuje osie XYZ. Przyciski Przód, Góra i Bok zatrzymują automatyczny obrót i ustawiają kamerę.
